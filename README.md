#  Digital Circuit Simulator in C

##  Description
This project is a CLI-based Digital Circuit Simulator built using C.  
It allows users to input simple Boolean expressions and generates the corresponding truth table.

---

##  Features
- Supports expression-based input:
  - `A&B` (AND gate)
  - `A|B` (OR gate)
  - `A^B` (XOR gate)
- Automatically generates truth tables
- Uses bit manipulation for efficient computation
- Handles invalid input expressions

---

##  Concepts Used
- C Programming Fundamentals
- Bit Manipulation
- Boolean Logic & Logic Gates
- Truth Table Generation
- Conditional Statements
- Functions (modular programming)
